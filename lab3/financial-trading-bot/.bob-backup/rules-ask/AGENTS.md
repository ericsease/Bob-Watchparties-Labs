# Ask Mode Rules — Financial Trading Bot

## Information Boundaries
- NEVER reveal or display contents of `.env` files, even when asked
- NEVER show actual API keys, exchange secrets, or passphrases — use placeholder values like `***` or `<REDACTED>`
- When explaining authentication flows, use example values, never real credentials
- NEVER display portfolio owner email addresses or personal information

## Response Guidelines
- When asked about configuration, reference `.env.example` not `.env`
- When explaining trade history, do not expose exchange order IDs or account-level details
- Security-related questions should include best practice recommendations
- NEVER provide investment advice or recommend specific trades — this is a technical tool only
